
# User Guide

## 1. Introduction

This guide explains how to use the CM Kerala Public Grievance Redressal Portal.

The application supports three user roles:

- Citizen
- CMO Administrator
- Department Officer

Each role has different permissions and responsibilities.

## 2. Accessing the Application

Open the application in your browser.

```text
http://localhost:5173
```

The home page provides information about the grievance portal and navigation to public pages.

Available public pages:

- Home
- About
- How It Works
- Departments
- Contact
- FAQ

Users can register or log in using the navigation options.

## 3. Citizen User Guide

### 3.1 Citizen Registration

1. Open the application.
2. Click Register.
3. Enter your name, email, mobile number, and password.
4. Submit the registration form.
5. Log in using your registered credentials.

### 3.2 Citizen Login

1. Open the Login page.
2. Enter your registered email and password.
3. Click Login.
4. The application redirects you to the Citizen Dashboard.

### 3.3 Citizen Dashboard

The dashboard provides:

- Total submitted grievances.
- Pending grievances.
- Resolved grievances.
- Recent grievance details.
- Quick access to grievance submission and tracking.

### 3.4 Submit a Grievance

1. Open the Citizen Dashboard.
2. Click Submit Grievance.
3. Select the district.
4. Select the grievance category.
5. Enter the complaint subject.
6. Provide a detailed description.
7. Upload supporting documents or images if required.
8. Submit the grievance.

After successful submission, the system generates a unique reference number.

Keep this reference number for future tracking.

### 3.5 Track a Grievance

1. Open the grievance tracking page.
2. Enter the grievance reference number.
3. Submit the tracking request.
4. View the current grievance status and available history.
5. Review resolution details when the grievance is resolved.

### 3.6 Submit Feedback

After a grievance is resolved:

1. Open the grievance tracking page.
2. View the resolved grievance.
3. Enter a rating.
4. Add feedback comments if required.
5. Submit feedback.

### 3.7 Citizen Logout

Click the Logout button in the dashboard to end the session.

## 4. CMO Administrator User Guide

### 4.1 Administrator Login

1. Open the Login page.
2. Enter administrator credentials.
3. Click Login.
4. The application redirects to the Administrator Dashboard.

### 4.2 Administrator Dashboard

The dashboard displays:

- Total grievances.
- Pending grievances.
- Resolved grievances.
- Overdue grievances.
- Grievance statistics and charts.
- Recent grievance information.

### 4.3 Manage Grievances

1. Open the Grievances page.
2. View all submitted grievances.
3. Use search and filters to find specific complaints.
4. Open a grievance to view its details.
5. Review complaint information and attachments.

### 4.4 AI Grievance Analysis

1. Open a grievance.
2. Select the AI analysis option.
3. Wait for the analysis response.
4. Review the suggested department, category, priority, and summary.
5. Use the suggestions as decision-support information.

AI suggestions must be reviewed before making administrative decisions.

### 4.5 Assign Department and Officer

1. Open the grievance details.
2. Select the appropriate department.
3. Select an officer from that department.
4. Confirm the assignment.

The grievance is assigned to the selected officer for further investigation.

### 4.6 Review Action-Taken Reports

1. Open the assigned grievance.
2. Review the officer's investigation remarks.
3. Read the submitted action-taken report.
4. Approve the report and resolve the grievance, or request further action.

### 4.7 Administrator Logout

Click Logout to end the administrator session.

## 5. Department Officer User Guide

### 5.1 Officer Login

1. Open the Login page.
2. Enter officer credentials.
3. Click Login.
4. The application redirects to the Officer Dashboard.

### 5.2 Officer Dashboard

The dashboard displays grievances assigned to the logged-in officer.

Officers can view the relevant grievance information and processing status.

### 5.3 View Assigned Grievance

1. Open the Officer Dashboard.
2. Select an assigned grievance.
3. Review the complaint details.
4. Check available attachments.

### 5.4 Investigate Grievance

1. Open the grievance details.
2. Update the status to In Progress.
3. Enter investigation remarks.
4. Save the update.

### 5.5 Submit Action-Taken Report

1. Open the grievance details.
2. Enter the action-taken report.
3. Provide relevant resolution information.
4. Submit the report.
5. Wait for administrator review.

### 5.6 Officer Logout

Click Logout to end the officer session.

## 6. Grievance Status Reference

| Status | Meaning |
|---|---|
| Submitted | Citizen has submitted the complaint. |
| Under Review | Administrator is reviewing the complaint. |
| In Progress | Department officer is investigating the complaint. |
| Resolved | Administrator has approved the resolution. |
| Reopened | Further action is required. |

## 7. Important Notes

- Citizens should keep their grievance reference numbers safe.
- Uploaded files must follow the supported file type and size restrictions.
- AI-generated suggestions are not final administrative decisions.
- Officers can access only grievances assigned to them.
- Administrators are responsible for reviewing action-taken reports.
- This application is a recruitment prototype and is not an official government service.

## 8. Conclusion

The portal provides a structured process for submitting, assigning, investigating, tracking, and resolving public grievances.

Each user role can access the features relevant to its responsibilities through the application's role-based access system.
